# C4.5 - Árbol de decisión (Dataset Wine)

Implementación del algoritmo C4.5 para clasificación del dataset Wine (UCI ID 109).

## Requisitos

- Python 3
- Librería `ucimlrepo`

## Instalación

```bash
pip install ucimlrepo
```

## Ejecución

```bash
python c4_5.py
```

El programa descarga el dataset Wine desde UCI, divide los datos en 80 % entrenamiento y 20 % test, construye el árbol C4.5, evalúa la precisión y guarda el reporte en `reporte_test.txt`.
